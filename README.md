# 8×8 点阵屏可视化调试器

> 点阵屏取模工具：点格子直接得到 C 字模数组，不用再手算二进制。

## 它解决什么

给 8×8 点阵屏画一个图案，传统流程是拿纸画格子、再手算每行的二进制、再转十六进制。图案稍复杂一点就会算错，而且改一个像素要全部重算。

这个小工具把流程压成一步：**点格子 → 直接复制 C 数组**。

## 关键实现

- 点击 / 拖动连续点灯，侧边栏取色，支持多色图案
- 实时生成 `unsigned char code[]` 形式的字模数组和显式坐标，两种格式都能直接用
- 纯前端单文件，无需安装环境，可离线使用

## 技术栈

- **形态**：单文件 HTML / CSS / JS，零依赖、双击即用
- **输出**：C 字模十六进制数组 + 点阵坐标
